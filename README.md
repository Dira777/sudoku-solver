#  Sudoku Solver

An interactive command-line Sudoku game built in Python that generates a unique random puzzle every run, accepts user input, validates moves in real time, and detects when the puzzle is solved.

---

##  Features

-  Random puzzle generation on every run
-  Real-time move validation based on Sudoku rules
-  Warns the user on invalid or conflicting moves
-  Solvability check — ensures every generated puzzle has a valid solution
-  Detects when the puzzle is correctly and completely solved
-  Option to quit the game at any time

---

##  Concepts Used

| Concept | Usage |
|---|---|
| Backtracking | Solving and validating the puzzle |
| Recursion | Core of the solvability checker |
| 2D Arrays | Grid representation |
| Input Validation | Handling invalid user inputs gracefully |

---

##  Tech Stack

- **Language:** Python 3
- **Libraries:** `random` (built-in, no installation needed)
